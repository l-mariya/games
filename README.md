# Игра-подарок — шаблон

Мобильная мини-игра «Как хорошо ты знаешь…?» на чистых HTML/CSS/JS. Статический сайт: без бэкенда, без сборки, без зависимостей.

## Структура

```
gift-game/
├── index.html        каркас страницы
├── style.css         оформление (цвета — CSS-переменные, настроения карточки результата)
├── config.js         ВСЕ тексты, вопросы, реакции, концовки, ачивки, пасхалка, бонус
├── script.js         движок игры (трогать не нужно)
└── assets/
    ├── hero.svg      иллюстрация на старте
    └── favicon.svg   иконка вкладки
```

## Под нового клиента — только `config.js`

| Что поменять | Где |
|---|---|
| Имя, повод | `hero`, `start`, `intro`, `greeting.title` |
| Рассказчик (кто комментирует ответы) | `narrator` — имя и эмодзи-аватар; блок можно удалить |
| Вопросы и реакции | `questions` — `id`, `options[].text`, `options[].reply`, `correct` (номер с нуля), `tag` |
| Бонусный вопрос | `bonus` — после какого вопроса (`after`), при каком условии (`when`), сам вопрос |
| Пасхалка | `easterEgg` — условие, секретная реплика, P.S. в письме |
| Концовки | `results` — `minScore`, `mood`, `medal`, `label`, `title`, `text`, `celebrate` |
| Ачивки | `achievements` — `icon`, `title`, `text`, `when`, `secret` |
| Поздравление | `greeting.paragraphs`, `greeting.signature` |
| Цвета | `theme.colors` (включая `gold` для бонуса и легендарной концовки) |
| Иллюстрация / фон | `theme.heroImage`, `theme.backgroundImage` (файл положить в `assets/`) |
| QR-код | `share.qrImage` |

### Условия `when`

Одинаково работают в ачивках, пасхалке и бонусе. Все поля должны выполниться одновременно.

- `minScore: 60` — набрано не меньше N баллов
- `perfect: true` — все основные вопросы отвечены верно
- `picked: ['wake:2', 'friends:3']` — выбраны эти варианты (id вопроса : номер варианта с нуля)
- `streak: 3` — N верных ответов подряд
- `tags: { chaos: 2 }` — выбрано N вариантов с тегом
- `egg: true` — найдена пасхалка

### Стили карточки результата

`style.css`, раздел `result card`. Настроение задаётся атрибутом `data-mood`: `legend`, `good`, `base`. У каждого — свой набор переменных `--rc-*` (фон, текст, акцент, кнопки). Новое настроение — новый блок `.result-card[data-mood='…']` и то же имя в `results[].mood`.

Количество вопросов любое — прогресс, максимум баллов и счётчики на старте считаются сами. Старые конфиги (варианты-строки, `right`/`wrong`) тоже работают.

## Запуск локально

Открыть `index.html` двойным кликом в браузере. Либо локальный сервер:
`python3 -m http.server 8000` → http://localhost:8000 (с телефона в той же Wi-Fi сети — http://IP-компьютера:8000).

## Публикация

- **GitHub Pages:** загрузить файлы в репозиторий → Settings → Pages → Branch `main`, папка `/ (root)`.
- **Netlify Drop:** перетащить папку на app.netlify.com/drop — ссылка появится сразу.
- **Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → загрузить папку.
