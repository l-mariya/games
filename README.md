# Игры-подарки

Каждая игра — отдельная папка. Адрес игры: `https://l-mariya.github.io/games/<папка>/`

```
games/
├── index.html        стартовая страница со списком демо
├── masha/            демо: день рождения
└── anniversary/      демо: годовщина
```

## Новая игра под клиента

1. Скопировать папку `masha/` целиком и переименовать, например `sveta-k4t9`. Лучше, чтобы название было неочевидным: ссылку не угадать.
2. В новой папке поменять `config.js`, при желании — картинки в `assets/`.
3. Загрузить папку в репозиторий. Через 1–2 минуты игра откроется по адресу `…/games/sveta-k4t9/`.

В `index.html` каждой игры стоит `noindex`, чтобы игры не попадали в поисковики. На стартовую страницу клиентские игры добавлять не нужно.

Подробно о том, что где менять в `config.js`, — в комментариях внутри файла.
